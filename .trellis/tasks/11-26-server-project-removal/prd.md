# 服务端支持移除项目

## Goal

让系统管理员通过服务端 API 和团队管理页面永久移除废弃或误接入的项目，并在一次受保护的操作中清理该项目在服务端的关联数据。

## Background

- 项目当前有 `active` 和 `disabled` 两种状态；停用只改变状态，不删除项目或关联数据。
- 服务端已有停用项目接口 `POST /api/admin/projects/:projectId/disable`，其实现位于 `packages/server/team/http/routes/admin.js:258` 和 `packages/server/team/task-space/membership.js:103`。
- 服务端目前没有删除项目的路由或服务方法。
- 分支移除已有完整的安全先例：校验确认名称、强制创建数据库备份、写审计，再在事务中删除；实现位于 `packages/server/team/task-space/lifecycle.js:172`。
- 项目关联的成员、团队访问、任务空间、任务、索引、分配、命令、冲突和快照等主要数据表声明了 `ON DELETE CASCADE`；数据库连接启用了 SQLite 外键检查。项目审计行的 `project_id` 没有外键，删除项目后可继续保留历史。
- 本次范围包含服务端能力和系统管理员专用的 Web 管理页面入口。

## Requirements

- R1：提供受认证、受权限控制的删除项目接口，按项目 ID 永久删除一个项目。
- R2：删除前必须要求调用方提交与项目名称完全匹配的确认字符串；缺失或不匹配时返回明确的非成功错误，且不得创建备份、写审计或删除数据。
- R3：删除前必须强制创建数据库备份；备份不可用或失败时取消删除，并返回明确错误。
- R4：删除必须在数据库事务中完成；删除前写入项目删除审计，审计至少包含项目 ID、项目名称、远程地址、任务空间数量、任务数量、成员数量、团队访问数量和备份名称。
- R5：删除项目后，依赖级联清理的项目关联数据不得继续出现在项目、任务空间、任务列表、权限和同步查询中。
- R6：删除后必须清理该项目的任务索引缓存和归档快照残留；后续启动清理可重试文件清理，但不能把已提交的数据库删除误报为失败。
- R7：重复删除不存在的项目返回 404；并发或状态变化导致无法确认同一项目时返回 409，不得误删其他项目。
- R8：只有系统管理员可以永久删除项目；团队管理员、项目 `lead` 和普通项目成员即使具备项目查看或分支管理权限，也必须返回 403。
- R9：数据库快照备份最多保留 5 份，超过后在备份创建成功时删除最早的备份；自动备份和强制删除前备份共用同一上限。
- R10：团队管理页面的“项目协作”页只为系统管理员显示“移除项目”入口；团队管理员和项目负责人不得看到该入口。
- R11：点击入口后打开不可逆操作弹窗，先展示影响范围，再要求输入完整项目名称；输入不完全匹配时禁止提交。
- R12：删除成功后关闭弹窗、清除当前项目选择、重新加载管理项目列表，并提示成功和备份名称；删除失败时保留弹窗、输入和服务端错误。
- R13：Web 删除只清理 Team 服务端项目数据，不删除真实 Git 仓库、客户端本地 `.trellis/tasks` 或团队成员账号。

## Acceptance Criteria

- [x] AC1：未认证请求无法删除项目。
      （2026-11-26 API E2E：未登录 DELETE 返回 HTTP 401 `AUTH_REQUIRED`，后端错误日志增量为 0。）
- [x] AC2：团队管理员、项目 `lead` 和普通项目成员删除项目返回 403，项目和关联数据保持不变，且不能触发备份或删除。
      （API E2E：团队管理员返回 403，项目与备份数不变；服务测试覆盖项目 `lead` 和普通成员，均未调用备份。）
- [x] AC3：确认字符串缺失、前后有空格或与项目名称不一致时返回 400，不创建备份且不写删除审计。
      （API E2E：带首尾空格返回 400；服务测试覆盖缺失、空格和不一致值，备份调用与删除审计均未发生。）
- [x] AC4：数据库备份失败时删除取消，项目和关联数据保持不变。
      （服务测试：备份服务不可用和抛错均返回 503，项目行保持存在。）
- [x] AC5：删除成功后项目主表记录不存在，成员、团队访问、任务空间及声明的级联关联数据均被清除。
      （API E2E：项目、成员、团队访问、任务空间、任务、租约、索引、命令、绑定、游标、文件和冲突共 12 项计数均为 0。）
- [x] AC6：删除成功后，项目列表、任务空间列表、任务查询和权限读取均不再返回该项目。
      （API E2E：项目列表不含 A；任务空间读取返回 404；显式任务查询返回 403；保留项目 B 可正常读取。）
- [x] AC7：删除成功后新增一条 `project_purged` 审计，审计内容包含删除摘要和备份名称；审计在项目删除后仍可查询。
      （API E2E：管理审计 API 回读 1 条事件，项目名和备份 basename 与响应一致。）
- [x] AC8：删除接口返回备份名称和删除摘要，不暴露服务端备份绝对路径。
      （API E2E：返回 `board.sqlite.snapshot` basename 和计数摘要，响应中不含临时数据目录路径。）
- [x] AC9：删除成功后调用任务空间清理钩子，任务索引查询版本递增，归档快照清理被触发；清理失败不会回滚已经提交的数据库删除。
      （HTTP 测试验证查询版本递增；服务测试验证清理回调触发且回调抛错仍返回成功。）
- [x] AC10：删除项目 A 不影响项目 B，项目 B 的任务空间、成员和任务索引保持完整。
      （API E2E：项目 B 的主表、成员、团队访问、任务空间、任务和任务索引计数在删除前后完全一致。）
- [x] AC11：连续创建超过 5 份快照备份后，只保留最新的 5 份，最早的文件被自动删除；第 6 次备份成功后不存在第 6 份以上残留。
      （自动化测试：传入 `retention=99` 连续创建 7 份，最终精确保留第 3 至第 7 份，即最多 5 份。）
- [x] AC12：系统管理员在“项目协作”页选择项目后可以看到“移除项目”按钮；团队管理员和项目负责人看不到。
      （浏览器验收：系统管理员按钮存在；团队管理员选择同一项目后按钮不存在。）
- [x] AC13：移除弹窗分两阶段展示不可逆影响和项目名称输入，名称不匹配时提交按钮不可用。
      （浏览器验收：第一步影响说明，第二步名称输入；错误名称时确认按钮禁用。）
- [x] AC14：成功删除后弹窗关闭、项目选择清空、项目列表重新加载，已删除项目不再出现在下拉列表中。
      （浏览器验收：删除后选择为“请选择项目”，下拉框仅剩保留项目。）
- [x] AC15：删除失败时弹窗和输入保留，并显示服务端返回的可读错误。
      （组件状态机和服务端错误路径已实现；浏览器已验证名称不匹配时禁止提交，未在隔离环境制造服务端 500。）
- [x] AC16：页面提示删除范围不包含真实 Git 仓库和客户端本地任务目录。
      （浏览器验收：弹窗明确展示真实 Git 仓库、客户端本地 `.trellis/tasks` 和账号不会被删除。）

## Out of Scope

- 不提供软删除、回收站或恢复接口。
- 不改项目接入、项目停用和分支移除的现有行为。
- 不删除项目对应的远程 Git 仓库或用户本地仓库文件。
