# 首次项目关联自动同步与状态反馈优化

## Goal

首次关联本地项目时，把关联完成前已经存在、但尚未进入服务端的 Trellis 工作区变化同步到服务端，并让用户清楚看到关联过程、关联结果、冲突和项目当前关联状态。

## Background

- 当前本地项目已经关联成功，绑定状态为 `approved`，sidecar running 且事件流已连接。
- watcher 只在绑定生效后监听新的文件事件；[live-sync.js](../../../agent/live-sync.js:264) 没有在首次绑定或 sidecar 重启时补扫关联前已有的变化。
- 本次故障中，本地任务目录创建于 `2026-11-09 10:59:04`，绑定完成于 `11:00:04`，该任务因此没有上传。
- 关联完成后再次创建任务已验证正常：新任务在约 3 秒内上传，服务端形成实时 revision，并进入 `team_task_index`。
- 项目栏虽然收到了 `approved` 关联，但 [ProjectRail.tsx](../../../web/src/components/layout/ProjectRail.tsx:186) 只显示本地仓库名；仓库名与项目名相同时，界面几乎无法区分已关联和未关联。
- 关联点击期间只有对应图标脉冲动画，没有项目级 loading 文案；成功没有明确提示，失败只在项目栏底部显示一行错误。

## Requirements

### R1 首次关联基线同步

- 首次产生有效绑定后，客户端必须识别关联前已经存在且尚未进入服务端实时覆盖层的 `.trellis/tasks`、`.trellis/workspace` 和 `.trellis/.developer` 文本变化。
- 基线同步必须包含关联前新建的未跟踪任务、已修改任务文件和已删除任务文件。
- 已经与 Git 基线或服务端实时内容一致的普通文件不得重复上传。
- sidecar 重启、心跳刷新或重复收到同一有效绑定时，不得重复制造无意义的实时 revision。
- `read_only` 绑定不得上传本地变化。
- 基线同步失败必须可重试，并且不能删除或静默覆盖本地文件。

### R2 冲突处理

- 首次关联发现同一文件在本地和服务端都有不同内容时，必须给出明显提示。
- 冲突覆盖前必须保留可恢复的本地备份。
- 用户必须能识别冲突任务、冲突文件、服务端版本和本地备份位置。
- 冲突默认以服务端实时内容为准；客户端先备份本地内容，再覆盖本地文件并显示现有“一键复原”入口。
- 关联流程不能在用户不知情的情况下丢失本地或服务端内容。

### R3 关联过程反馈

- 点击关联后，目标项目必须立即进入明确的 loading 状态。
- loading 期间必须阻止同一项目重复提交关联。
- 用户取消目录选择时不得显示失败。
- 关联成功必须显示明确成功提示，并刷新项目关联状态。
- 关联失败必须显示与错误码对应的中文失败提示，且保留可再次尝试的入口。

### R4 项目列表状态

- 项目列表必须仅凭常驻文案或明显视觉状态区分“未关联”“关联中”“已关联”“只读”和“关联失效”。
- 已关联状态不能只依赖 hover tooltip 或与项目同名的仓库名。
- 状态更新后无需刷新整个页面即可在当前项目行体现。

### R5 兼容与边界

- 普通浏览器继续不显示本地关联入口。
- 团队服务端不得重新启动本地 `.trellis` watcher。
- 本次修复不得自动 commit、push 或改写 Git 历史。
- 实时同步仍只处理白名单内的 UTF-8 文本文件。

## Acceptance Criteria

- [ ] 关联前创建的本地任务在首次关联成功后 3 秒内出现在服务端实时数据和看板中。
- [ ] 关联前修改的 `task.json`、`prd.md` 等任务文件可在首次关联后同步。
- [ ] 关联前删除的已跟踪任务文件可在首次关联后同步为服务端删除状态。
- [ ] 未发生变化的普通 Git 文件不会因首次关联产生实时上传。
- [ ] 重复心跳、sidecar 重启和重复关联不会重复上传相同内容。
- [ ] `read_only` 项目只接收服务端内容，不上传本地变化。
- [ ] 同路径本地与服务端内容冲突时，服务端内容优先并覆盖本地；覆盖前生成本地备份，同时显示提示和一键复原入口。
- [ ] 点击关联后项目行立即显示“关联中”，并阻止重复点击。
- [ ] 取消目录选择不提示失败。
- [ ] 成功和失败分别出现明确中文提示，失败后可再次关联。
- [ ] 项目列表常驻区分未关联、关联中、已关联、只读和失效状态。
- [ ] 普通浏览器仍不显示关联入口，服务端 watcher 状态仍为 disabled。

## Out of Scope

- 自动 commit 或 push。
- 自动合并两个文本版本。
- 服务端直接扫描任意客户端本地目录。
- 普通浏览器中的本地项目关联能力。
- 删除、合并或自动修复冲突任务。
