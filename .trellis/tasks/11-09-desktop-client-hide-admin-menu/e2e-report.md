# 客户端登录后隐藏团队管理入口 E2E 报告

## 验证环境

- Vite 开发服务：`http://127.0.0.1:5173/`
- 浏览器通过启动脚本拦截 `/api/*` 并返回固定团队模式数据，避免依赖当前已失效的 4317 后端。
- 普通浏览器场景保持 `window.__TAURI__` 不存在。
- 客户端场景在页面脚本执行前注入 `window.__TAURI__.core.invoke`，模拟现有 Tauri 运行时特征。

## 验证结果

- 普通浏览器：头像菜单包含“待我接受、修改密码、团队管理、退出”，团队管理入口保持可见。
- Tauri 客户端模拟：侧栏出现“客户端后台”，头像菜单只包含“待我接受、修改密码、退出”，未出现“团队管理”。

## 未验证
