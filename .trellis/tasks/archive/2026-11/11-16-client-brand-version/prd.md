# 客户端显示可配置品牌名与版本号

## Goal

在 Windows 桌面客户端左上角显示可配置的品牌名，并在品牌名下方显示当前客户端版本号。
未配置品牌名时继续显示 `Trellis Board`。

## Requirements

- 桌面客户端 Board 页左上角继续显示现有 Logo；品牌名作为主标题，客户端版本号位于品牌名下方。
- 版本号必须来自当前桌面客户端的包版本，而不是 Web 包、服务端或某个项目任务的版本。
- 版本号格式统一为 `v<版本>`，例如 `v0.4.27`。
- 品牌名复用桌面客户端已有的 `productName` 配置，默认值为 `Trellis Board`；修改该配置后，Board 左上角显示新名称。
- 品牌名为空、缺失或只有空白时，回退为 `Trellis Board`。
- 非桌面浏览器没有可信的客户端版本上下文：继续显示默认品牌名，不显示客户端版本号。
- 品牌名可包含中文、英文和空格；较长名称不得挤压导航、搜索或右侧操作区，窄视口下沿用现有品牌隐藏策略。
- 品牌区的链接可访问名称应包含当前品牌名，不能继续硬编码为 `Trellis Board 首页`。
- 不新增品牌设置页面、不改变登录页文案、不改变托盘菜单名称，也不引入第三方依赖。

## Acceptance Criteria

- [x] 默认桌面客户端左上角显示 `Trellis Board`，其下一行显示 `v<当前客户端版本>`。
- [x] 将客户端 `productName` 配置为其他非空名称后，桌面 Board 左上角显示该名称，版本号仍显示在其下方。
- [x] 将品牌名配置为空或仅空白时，界面回退显示 `Trellis Board`。
- [x] 普通浏览器打开 Board 时显示 `Trellis Board`，不显示客户端版本号。
- [x] 长品牌名和窄窗口下，导航、搜索、创建任务及账号操作仍可用，版本号不与标题重叠。
- [x] 品牌链接的可访问名称与当前显示品牌一致。
- [ ] 相关静态契约测试、Rust 测试和 Web 测试通过；最后只在全部开发完成后执行一次项目规定的编译/验证。
