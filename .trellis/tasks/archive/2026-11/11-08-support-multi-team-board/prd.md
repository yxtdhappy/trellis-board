# 支持用户多团队任务看板

## Goal

让团队归属完全由服务端成员关系决定。用户登录后无需选择活动团队，即可查看自己有权访问的多个团队项目与任务；桌面设备和 Agent 授权不再被单一团队限制。

## Background

- 当前数据库已经通过 `team_member` 维护账号与团队的成员关系，管理员可以给同一账号分配多个团队。
- 当前登录 Session 仍保存单一 `active_team_id`，自动选择第一个团队。
- 项目查询、任务索引、保存视图、WIP 设置和 Agent 授权大量依赖 `actor.activeTeamId`。
- 当前 Web 端通过 `TeamSwitcher` 切换活动团队并刷新页面，普通用户一次只能看到所选团队的数据。
- 设备注册和项目绑定目前把团队 ID 固化到设备或绑定记录中，无法自然支持一个用户的多团队项目。

## Requirements

- 登录只验证账号身份和密码，不要求用户预先选择团队，也不在登录时把 Session 固定到一个活动团队。
- 服务端继续作为团队成员关系的唯一事实源；用户可访问团队集合必须来自实时成员关系和管理员配置。
- 登录后的运行时信息必须返回当前用户的全部有效团队成员关系、团队名称和用户在该团队中的角色。
- 默认任务看板必须允许用户直接看到其全部授权团队的数据，不需要先切换活动团队。
- 用户可以在登录后按团队筛选视图；团队筛选仅影响展示，不得改变登录身份或其他团队的授权状态。
- 保存视图和 WIP 软上限按团队独立；“全部团队”视图使用独立的账号级全局配置。切换团队筛选时不得混用其他团队的配置。
- 项目、任务、查询结果、游标和写操作必须携带或可推导所属团队，并在服务端校验当前用户对该团队的成员关系和角色。
- 用户访问未加入、已禁用或已被移除的团队时必须被服务端拒绝；不得只依赖前端隐藏。
- 任务创建、委派、接受、依赖、保存视图和其他写操作必须按目标项目所属团队执行权限检查。
- 桌面设备和 Agent 凭证应绑定“用户 + 设备”，而不是固定绑定一个活动团队；项目绑定按项目所属团队单独授权。
- 一个设备上的 Agent 可以在权限允许时绑定同一用户多个团队下的项目。
- 单团队成员用户的现有使用方式应保持简洁，登录后直接进入默认全部团队视图。
- 团队成员变更后，后续查询和操作必须立即反映新的权限集合；相关查询缓存和分页游标不得继续返回已移除团队的数据。

## Acceptance Criteria

- [x] 同一账号属于两个团队时，登录过程中不出现必选的团队选择，也不因活动团队为空而拒绝登录。
- [x] 登录后运行时接口返回该账号全部有效团队成员关系及对应角色。
- [x] 默认任务视图可展示两个团队的任务，并为每条任务标明所属团队。
- [x] 选择单个团队后只显示该团队任务；“全部团队”视图恢复展示所有授权团队任务。
- [x] 选择团队 A、团队 B 或“全部团队”时，分别读取该作用域独立的保存视图和 WIP 软上限。
- [x] 修改团队 A 的保存视图或 WIP 不会改变团队 B 与“全部团队”的同名配置。
- [x] 用户直接请求未加入团队的项目、任务或写操作时返回权限错误。
- [x] 管理员移除某团队成员后，该用户下一次查询不再看到该团队数据，旧游标和缓存不能绕过授权。
- [x] 同一桌面设备可完成注册，并在权限允许时绑定不同团队下的项目，无需重新选择活动团队。
- [x] Agent 对无权限项目发起绑定时被服务端拒绝。
- [x] 单团队用户登录后无需任何额外点击即可看到该团队任务，行为不退化。
- [x] 现有登录、项目权限、任务写入、设备撤销和审计测试全部通过，并新增多团队与成员变更测试。

## Out of Scope

- 移除设备令牌并改成账号密码直连 sidecar；该交互调整需要单独评审。
- 移除管理员配对码兜底流程。
- 跨团队合并角色或跨团队自动提权。
- 多实例部署和数据库后端替换。

## Notes

- 已确定默认首页采用“全部团队”聚合看板，并提供团队筛选；不采用团队入口页。
- 已确定保存视图和 WIP 采用“按团队独立 + 全部团队全局作用域”，不采用账号级单一全局配置。
- 这是跨后端、前端、数据库状态和 Agent 授权的复杂任务，实施前需要 `design.md` 和 `implement.md`。
- 当前活动团队的证据入口：`server/team/auth.js`、`server/team/teams.js`、`server/team/projects.js`、`server/team/task-index.js`、`server/team/agents.js`、`web/src/features/admin/TeamSwitcher.tsx`。
