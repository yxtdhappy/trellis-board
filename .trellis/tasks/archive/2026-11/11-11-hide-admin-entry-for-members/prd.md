# 普通成员隐藏团队管理入口

## Goal

修复Web端普通成员仍显示团队管理入口的问题，仅系统管理员、团队管理员和可管理项目的负责人显示，后端鉴权不变

## Background

- 当前 Web 端在非 Tauri 环境下无条件把 `adminHref` 设置为 `/admin.html`，因此所有已登录用户都会看到“团队管理”菜单。
- 实测普通账号 `kyf` 的 `systemAdmin=false`，团队角色为 `member`，所有管理能力均为 `false`。
- 该账号访问用户、团队、项目、Agent 和审计管理接口均返回 `403`，不存在实际越权。
- 管理控制台允许系统管理员、团队管理员和可管理项目的负责人进入，不能简单限制为仅系统管理员可见。

## Requirements

- 普通团队成员在 Board TopBar 中不得看到“团队管理”入口。
- 系统管理员必须继续看到“团队管理”入口。
- 任一团队的团队管理员必须继续看到“团队管理”入口。
- 至少可管理一个项目的项目负责人或项目管理者必须继续看到“团队管理”入口。
- “团队管理”入口只负责导航，不得改变现有服务端角色模型或接口鉴权。
- 普通用户仍可正常登录 Board，保持现有账号创建和登录流程不变。
- Tauri 客户端现有不显示该入口的行为保持不变。

## Acceptance Criteria

- [x] `systemAdmin=false`、团队角色为 `member` 且无可管理项目的账号看不到“团队管理”菜单。
- [x] 系统管理员能看到“团队管理”菜单。
- [x] 团队管理员能看到“团队管理”菜单。
- [x] 至少可管理一个项目的负责人能看到“团队管理”菜单。
- [x] 普通成员直接访问 `/admin.html` 时仍显示“当前账号没有管理入口”。
- [x] 普通成员访问管理 API 仍返回现有 `403`，本次不放松任何后端权限。
- [x] Web 类型检查、生产构建和相关前端测试通过。

## Non-goals

- 不禁止普通用户登录 Board。
- 不修改系统管理员、团队管理员、项目负责人和普通成员的角色定义。
- 不重构管理控制台页面或服务端权限接口。
