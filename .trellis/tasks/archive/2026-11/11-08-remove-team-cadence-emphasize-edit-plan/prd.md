# 精简概览与任务详情操作区

## Goal

减少概览中含义不准确的指标，让任务详情里的计划编辑入口更显眼，并移除无用操作入口。

## Background

- 概览中的“团队节奏”实际展示当前任务集合中去重后的负责人数量，不是真正的团队节拍或工作量指标。
- 任务详情中的“编辑计划”目前使用 ghost 小按钮，视觉层级过低，容易与“撤销最近操作”等辅助操作混淆。
- 用户明确要求移除无用的“撤销最近操作”入口。

## Requirements

- R1：从概览中移除“团队节奏”卡片，概览仅保留“进行中”“归档任务”“需要关注”三张卡片。
- R2：清理仅为“团队节奏”卡片服务的 `owners` 属性及调用参数；不删除负责人筛选、团队视角或其他仍在使用负责人数据的逻辑。
- R3：提高任务详情中“编辑计划”按钮的视觉层级，使用主操作按钮样式和更大的点击区域。
- R4：保持“编辑计划”原有的展开、收起、字段回填和保存行为不变。
- R5：从任务详情操作区移除“撤销最近操作”按钮，不在原位置留下空白占位。
- R6：本次只移除前端入口，不删除后端撤销 API、历史记录或恢复能力。

## Acceptance Criteria

- [x] 概览页面不再出现“团队节奏”卡片，剩余三张卡片在桌面和窄屏布局下正常显示。
- [x] `Overview` 不再接收或使用 `owners`，调用方不再传入该参数，前端构建通过。
- [x] 任务详情中的“编辑计划”使用明显的主操作按钮样式，点击后仍能正常展开并保存计划字段。
- [x] 任务详情中不再出现“撤销最近操作”按钮或对应占位，依赖操作和其他详情功能不受影响。
- [x] 仓库中不再存在本次 UI 变更引入的未使用导入、变量或类型成员。

## Out of Scope

- 不修改“团队节奏”可能涉及的后端统计或数据库数据。
- 不删除团队视角中的“按负责人统计”列表。
- 不删除撤销 API、任务历史或底层撤销逻辑。
- 不调整任务详情中的阶段证据、计划字段或依赖操作逻辑。

## Notes

- 轻量任务，PRD-only；实现范围限定在 `Overview`、任务详情对话框及其直接调用方。
