# 归档索引团队/项目筛选 E2E

## 环境

- 前端：独立 worktree 的 Vite 开发服务器。
- 浏览器：用户现有已登录标签页，同一主机名下通过 Vite `/api` 代理访问现有团队后端。
- 后端：现有团队模式服务，未重启、未切换数据目录。

## 结果

- 归档索引负责人右侧显示“团队”“项目”两个带搜索下拉。
- 团队输入“大数据”后，下拉只剩“大数据团队”，选择后查询继续成功。
- 项目输入“trellis-board”后，下拉只剩对应项目，选择后结果收窄。
- 全项目归档总数为 702；选择 `trellis-board` 后总数为 104，分页显示第 1/6 页。
- 当前页任务均显示为“大数据团队 · trellis-board”。
- 左侧全局项目仍为“全部项目”，说明归档页筛选未修改全局筛选。
- 点击归档页“刷新”后，团队“大数据团队”和项目“trellis-board”均保留。
- 项目输入不存在的名称时显示“没有匹配项”。
