# 实现团队 Web 控制台

## Goal

在现有原生 Web 看板基础上增加登录、权限化团队视图、任务接受和团队管理界面，同时保留现有单机看板体验。

## Dependencies

- 依赖父任务 `11-03-team-board` 的 UI 边界和安全约束。
- 实现依赖 `11-03-team-core-service` 提供的认证、RBAC 和团队 API。

## In Scope

- 登录页、会话恢复、退出和统一 401 处理。
- 按权限过滤的跨项目混合分页列表、单项目分组看板、待我接受队列。
- 项目负责人/成员创建任务和委派；服务端发布状态可见。
- 系统管理员用户、项目、设备管理入口。
- 项目负责人成员管理和 Agent 绑定确认。
- Git 同步失败、项目 stale、Agent 离线/版本过旧/本地阻塞的可操作提示。
- standalone 模式继续使用现有页面和交互。

## Out of Scope

- 自定义主题、前端框架、构建链和第三方组件库。
- 绕过服务端权限的前端授权。
- 评论、通知、审批流和 SSO 页面。
- Windows Agent 安装 UI。

## Acceptance Criteria

- [ ] team 模式未登录用户只能看到登录页；登录后只看到有权项目。
- [ ] 系统管理员没有项目角色时不显示任务写入口，服务端也拒绝写请求。
- [ ] 项目负责人和成员都能创建任务、选择有效负责人并看到 push 结果。
- [ ] 团队看板默认显示 `/api/tasks/query` 的跨项目分页任务；切换项目后显示 `/api/board` 的完整分组看板。
- [ ] 跨项目搜索、项目、负责人、阶段、优先级、标签、截止、阻断筛选在服务端执行，分页不重复、不遗漏、不越权。
- [ ] 200 个在线会话下，轻量状态轮询约 3 秒一次，相关 `queryRevision`/`boardVersion` 未变化时不会重复下载任务页。
- [ ] 服务端 `queryDay` 变化时刷新截止/长期未动筛选，跨午夜后不继续展示昨天的结果。
- [ ] 待接受任务只允许当前负责人接受，成功后队列和详情同步更新。
- [ ] Git/Agent 错误可定位到项目、设备、结果和操作 ID，不展示敏感值。
- [ ] 所有服务端文本经 `safe()`，Markdown 只经 `renderMarkdown()`。
- [ ] 1440px 桌面和 860px 以下布局可用；键盘焦点、对话框、错误状态和 reduced-motion 保持可达。
- [ ] 浏览器控制台无未处理错误，standalone 页面回归通过。
