管理员兜底：使用配对码

配对码仅用于管理员排障，不作为桌面端默认注册方式；可在 Board 设备页生成。

初始化 workspace

选择一个本地项目目录。客户端会写入 .trellis、.opencode、 .agents，并用当前设备注册账号的用户名初始化 developer；不会创建 Git 仓库。
