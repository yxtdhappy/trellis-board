# 迁移报告

每个 gate 的证据写在这里，不要只写在对话里。

| 文件 | 对应 gate |
|---|---|
| `00-feasibility.md` | 00 可行性 |
| `00b-judge.md` | 00b Judge |
| `01-map.md` | 01 依赖图/功能地图 |
| `02-inventory.md` | 02 缺口清单 |
| `slices/<id>.md` | 每个纵向切片 |
| `06-parity.md` | 06 收尾 |

规则：

- 计数用命令输出，不写“大概”“很多”。
- 未覆盖、跳过、失败都要写。
- 不把密码、token、用户隐私写入报告。
- 报告可以引用 `file:line`，不要复制大段源码。
